# JavaScript Calculator

Four-operation JavaScript calculator with arithmetic precedence, decimal support, error recovery and expression parsing without eval.

Part of my JavaScript practice work. Explore my complete projects on [GitHub](https://github.com/awaljanhematyar) or my [developer portfolio](https://hematyar-professional-portfolio.vercel.app/).

## Features

- Add, subtract, multiply and divide with normal precedence.
- Use decimal values and signed numbers.
- Clear all input or delete the last character.
- Show recoverable errors for invalid expressions and division by zero.
- Parse arithmetic without executing input as JavaScript.

## Run locally

```sh
git clone https://github.com/awaljanhematyar/calculator.git
cd calculator
```

Serve the folder using VS Code Live Server and open `index.html`. There is no npm installation or build step. Use a modern browser.
